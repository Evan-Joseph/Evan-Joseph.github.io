01研究方向

Research Interests

围绕“让模型在真实世界中理解任务进展并做出规划”这条主线,从评测诊断、训练策略到落地 Agent 系统逐层推进。

A1

多模态与具身智能

视觉-语言模型在真实机器人操作视频中的任务导向时空推理,衡量并提升对动态任务进展的理解。

A2

世界模型 / 交互式视频

面向第一视角与操作场景的时序建模,研究输入顺序偏置与时空幻觉的成因与缓解。

A3

长程具身规划

将长程任务重构为动作蓝图(Action Blueprint)生成,缓解全局规划不足与显式规划器的感知脱节。

A4

Agent 与强化学习

GUI Agent 的分步反馈强化学习,围绕原则约束的奖励建模与在线轨迹构建。
